# Gửi mod cho bạn

`scripts/package.sh` → `dist/minecraft-lab-<ngày>.zip` (jar mod + Fabric API + `INSTALL-vi.txt`). Gửi zip qua chat. Không publish lên Modrinth/CurseForge khi chưa có go-ahead của Huy. Bản mod tăng `mod_version` trong `mods/<id>/gradle.properties` khi đổi hành vi; bạn phải cài đúng cùng phiên bản với host.
